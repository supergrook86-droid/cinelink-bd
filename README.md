# CineLink BD Server 🎬

আপনার নিজের **মুভি স্ট্রিমিং ওয়েবসাইট** — ভিডিও আপলোড, অ্যাডমিন লগইন ও ডাইনামিক মুভি লিস্টসহ। ফ্রন্টএন্ড এক ফাইলে নয় — এখন পুরো সাইটটা সার্ভার দিয়ে চলে, আর আপনি **admin প্যানেল** থেকে মুভি যোগ/এডিট/ডিলিট করতে পারবেন, পোস্টার ও ভিডিও ফাইল আপলোড করতে পারবেন।

---

## কেমন কাজ করে (How it works)

```
ব্রাউজার → Node.js সার্ভার (Express)
              ├─ /admin  → লগইন + মুভি ম্যানেজ + ফাইল আপলোড
              ├─ /api/movies → সাইটে মুভি লিস্ট দেখায়
              ├─ uploads/  → আপলোড করা পোস্টার ও ভিডিও ফাইল
              └─ data/movies.json → মুভির সব তথ্য (ডাটাবেস)
```

## চালু করার নিয়ম (Windows/Mac/Linux)

**ধাপ ১ — Node.js ইনস্টল করুন** (একবারই):
https://nodejs.org → **LTS** ভার্সন ডাউনলোড করে ইনস্টল করুন।

**ধাপ ২ — প্রজেক্ট খুলুন ও ডিপেনডেন্সি বসান (একবারই):**

```bash
cd cinelink-bd-server
npm install
```

**ধাপ ৩ — সার্ভার চালু করুন:**

```bash
npm start
```

তারপর ব্রাউজারে খুলুন:
- সাইট: **http://localhost:3000**
- অ্যাডমিন প্যানেল: **http://localhost:3000/admin**

*(Windows-এ `start.bat` ডাবল-ক্লিক করলেই সার্ভার চলে — প্রথমবার নিজে npm install করে নেবে।)*

## লগইন

| | |
|---|---|
| ডিফল্ট ইউজারনেম | `admin` |
| ডিফল্ট পাসওয়ার্ড | `admin123` |
| **প্রথমবারের পর অবশ্যই বদলে নিন** | `node server.js --set-password <নতুন-পাসওয়ার্ড>` |
| (ইউজারনেমও বদলাতে চাইলে) | `node server.js --set-password <pass> --set-user <user>` |

## মুভি যোগ করা (Admin Panel)

1. `/admin`-এ লগইন করুন
2. **«+ নতুন মুভি যোগ»** বাটনে ক্লিক করুন
3. নাম, বছর, কোয়ালিটি, ভাষা ইত্যাদি দিন
4. **পোস্টার ফাইল** বা পোস্টার URL দিন
5. **ভিডিও ফাইল** (mp4/webm) আপলোড করুন — **অথবা** ভিডিও URL দিন:
   - সরাসরি `.mp4` লিংক (আপনার হোস্টিং/সার্ভার থেকে), বা
   - **YouTube লিংক** (`youtube.com/watch?v=…`, `youtu.be/…`, shorts)
   - ভিডিও না দিলে সাইটে ডেমো ক্লিপ বাজে (টেস্টিংয়ের জন্য)
6. **«সেভ করুন»** — হয়ে গেছে! সাইটে রিফ্রেশ করলেই নতুন মুভি দেখা যাবে

PINNED শেলফে আনতে চাইলে «PINNED শেলফে রাখুন» চেকবক্স টিক দিন। মুভি মুছলে তার আপলোড করা ফাইলগুলোও মুছে যায়।

## সবকিছু কোথায় রাখা হয়

| যেখানে | কী থাকে |
|---|---|
| `data/movies.json` | মুভির তালিকা (নাম, ভিউ, রেটিং — সব) |
| `data/admins.json` | লগইন তথ্য (পাসওয়ার্ড hash আকারে) |
| `uploads/posters/` | আপলোড করা পোস্টার |
| `uploads/videos/` | আপলোড করা ভিডিও |

## গুরুত্বপূর্ণ সেটিংস (Environment Variables)

```bash
PORT=3000              # সার্ভার পোর্ট
MAX_VIDEO_MB=2048      # ভিডিও আপলোড সীমা (ডিফল্ট 2048 MB)
ADMIN_USER=admin       # প্রথম ঢোকার ইউজারনেম
ADMIN_PASSWORD=admin123# প্রথম ঢোকার পাসওয়ার্ড
SESSION_SECRET=xyz     # সেশন সুরক্ষা (প্রোডাকশনে অবশ্যই দিন)
```

যেমন: `PORT=8080 npm start` — তাহলে সাইট চলবে http://localhost:8080

## ইন্টারনেটে (হোস্টিং) পাবলিক করা

**সহজ উপায় — Render (ফ্রি):**
1. [render.com](https://render.com) → New **Web Service**
2. GitHub-এ এই ফোল্ডারটা push করুন (নিচে দেখুন), অথবা upload করুন
3. Build Command: `npm install` → Start Command: `npm start`
4. Environment-এ `PORT` Render নিজে দেবে
5. Deploy হয়ে গেলে আপনার পাবলিক লিংক (যেমন `https://your-site.onrender.com`) — সেটাই ওয়েবসাইট

**নিজের VPS/হোস্টিং:**
```bash
npm install
nohup npm start > server.log 2>&1 &     # ব্যাকগ্রাউন্ডে চলে
# ভিডিও ফাইল বড় হলে সার্ভারে জায়গা নিশ্চিত করুন
```

**স্থায়ী চালু রাখতে (Linux VPS, PM2):**
```bash
npm install -g pm2
pm2 start server.js --name cinelink
pm2 save && pm2 startup
```

**সাবধানতা:** ফ্রি হোস্টিংয়ে ভিডিও স্টোরেজ সীমিত — বড় ফাইল নিজের VPS বা Cloudflare R2 / AWS S3-এ রাখুন আর URL বসান। সাইট টেস্ট করতে প্রথমে ছোট ফাইল দিয়ে দেখে নিন।

## সমস্যা হলে (Troubleshooting)

| সমস্যা | সমাধান |
|---|---|
| `npm install` কাজ করে না | Node.js LTS ইনস্টল করা আছে কিনা দেখুন (`node -v`) |
| পোর্ট 3000 ব্যস্ত | `PORT=3001 npm start` |
| ভিডিও আপলোড «file_too_large» | `MAX_VIDEO_MB=4096 npm start` |
| মুভি সেভ হয় না | প্রথমে `/admin`-এ লগইন করা আছে কি না দেখুন |
| সাইট খালি দেখায় | সার্ভার বন্ধ — টার্মিনালে `npm start` দিন |

## ইন্টারনেটে পাবলিক করা (GitHub + Render — ফ্রি) ও আর্নিং

### ধাপ ১ — GitHub অ্যাকাউন্ট ও রিপোজিটরি
1. https://github.com এ ফ্রি অ্যাকাউন্ট খুলুন
2. ডান ওপরের **"+ New repository"** → নাম দিন: `cinelink-bd` → সব ডিফল্ট রেখে **Create**
3. রিপোতে ঢুকে **"uploading an existing file"** লিংকে ক্লিক করুন
4. এই ফোল্ডারের **এই ফাইলগুলো** টেনে বসান (ভেতরের ফোল্ডারসহ): `server.js`, `package.json`, `package-lock.json`, `render.yaml`, `start.bat`, `.gitignore`, `public/` ফোল্ডার, `README.md`
5. **এগুলো কখনো আপলোড করবেন না:** `node_modules`, `uploads`, `data` (এগুলো আপনার কম্পিউটারের ফাইল — রিপোতে যাবে না)
6. Commit

### ধাপ ২ — Render থেকে ডেপ্লয়
1. https://render.com এ **Sign up with GitHub** দিয়ে ঢুকুন
2. **New → Blueprint** → আপনার GitHub কানেক্ট করুন → `cinelink-bd` রিপো বাছুন → Apply
3. ২-৫ মিনিট অপেক্ষা → পাবেন স্থায়ী লিংক: `https://cinelink-bd.onrender.com` 🎉
4. **জরুরি (একবারই):** Render ড্যাশবোর্ডে সাইটের → **Environment** → দুটো ভেরিয়েবল দিন:
   - `ADMIN_PASSWORD` = আপনার নিজের পাসওয়ার্ড (পাবলিকে `admin123` রাখা মানে কেউ চাইলে আপনার সাইটের মালিক হয়ে যাবে!)
   - `SESSION_SECRET` = যেকোনো দীর্ঘ এলোমেলো লেখা
5. **বিঃদ্র:** Render-এর ফ্রি প্ল্যানে ভিডিও আপলোড জায়গা খুব ছোট — বড় ভিডিও রাখতে Cloudflare R2 / AWS S3-এ ফাইল রাখুন আর URL বসান

### ধাপ ৩ — গুগল সার্চে পাওয়া
1. লিংক পাওয়ার পর https://search.google.com/search-console এ সাইট নিবন্ধন করুন → sitemap `https://cinelink-bd.onrender.com/robots.txt` যাচাই করুন
2. সার্চে র‍্যাংক আসতে সময় লাগে (সপ্তাহ-মাস) — এর মধ্যে লিংক শেয়ার করুন (ফেসবুক গ্রুপ, হোয়াটসঅ্যাপ, কমিউনিটি)

- **আইনি পথ:** নিজের বানানো বা অনুমতিপ্রাপ্ত কনটেন্ট দিয়ে সাইট ভরুন → ভালো ট্রাফিক হলে **Google AdSense** (বিজ্ঞাপন), অথবা **ডোনেশন/সাবস্ক্রিপশন** বাটন যোগ করুন।
- আর্নিং ট্রাফিকের উপর নির্ভর করে — দৈনিক হাজার ভিজিটের পরই বিজ্ঞাপনে অর্থ জমতে শুরু করে। ধৈর্য দরকার।
